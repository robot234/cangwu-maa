# 苍雾世界 Maa 助手

收菜、清体力、打竞技场，让日常少一点重复点击。

基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 和 [MXU](https://github.com/MistEO/MXU)，适用于 **苍雾世界国服 · MuMu · Windows x64**。

## 下载与使用

v0.4.9 更新：适配「艾吉斯·未解之谜」活动；活动扫荡结果不明时保留记录，阻止重复提交；修复资源副本开放标签、入口等待和中文载入识别。2026-10-30 已按保存配置完成16项日常及最终大厅检查，结果见 [本轮实测记录](docs/日常实测记录-2026-10-30.md)。自动补体力仍默认关闭。

1. 下载 **[CangwuMaa-Windows-x64.zip](https://github.com/robot234/cangwu-maa/releases/latest/download/CangwuMaa-Windows-x64.zip)**，完整解压到一个可写的文件夹。
2. 打开 MuMu，确认已安装苍雾世界国服。模拟器使用 **16:9 横屏**，建议设为 **1280 × 720**。
3. 双击 **启动苍雾助手.bat**，按系统提示允许启动。
4. 在助手右侧刷新、选择并连接 MuMu 设备，选择「国服」资源。
5. 需要自动打开游戏时，勾选最上方的 **开始游戏**；它默认不勾选，不勾选时请先手动进入游戏大厅。
6. 勾选其他需要的任务，展开卡片调整选项，点击 **开始任务**。

完整包已包含运行环境，无需安装 Python 或手动安装依赖。请下载上面的 ZIP，**不要下载 GitHub 自动生成的 Source code**，也不要在压缩包内直接运行。

助手可以先于模拟器打开；之后启动 MuMu，再刷新设备即可。始终使用根目录的启动入口。

## 能做什么

| 功能 | 可用设置 |
| --- | --- |
| 开始游戏 | 独立可选任务，默认不勾选；选中后自动打开游戏、处理开始页并进入大厅 |
| 指挥室收菜 | 收取战斗训练、体能锻炼和物资生产资源 |
| 远征收取与续派 | 收取已完成远征，沿用保存的队伍续派；默认 12 小时 |
| 邮件与好友 | 领取邮件附件、好友体力 |
| 首页推荐免费礼包 | 领取「通常礼包」中的免费礼包，已领取则跳过 |
| 活动清体力 | 扫荡「闪耀之始-7」，可设置保留体力 |
| 续航计划（限时） | 领取活动合集里「续航计划」的累计体力消耗奖励；活动结束后自动跳过 |
| 竞技场 | 使用现有演习券进行代理，可设置本轮用票上限 |
| 任务与通行证 | 领取任务列表、每日／每周／每月积分奖励及通行证奖励 |
| 自选商店兑换 | 精英、后勤、联合、大师商店；逐项选择商品和数量 |
| 装甲进阶 | 逆爱、索贝克、利维坦分别设置每周次数，合计最多 5 次 |
| 异兽清剿 | 经验获取、盾币获取、幻化星碎，分别设置1～10关和每日目标次数 |
| 核心制造 | 六种核心分别设置1～5关和每日目标次数，未开放跳过 |
| 队员特训 | 防卫、攻击、火力、支援觉醒分别设置1～10关和每日目标次数，未开放跳过 |
| 自动补体力 | 默认关闭；道具个数、结晶购买次数及结晶总额分别设每日上限 |
| 更新与资源同步 | 自动更新可开关，也可手动检查新版、同步当前版本的识别资源 |

商店兑换、装甲进阶和三个资源副本默认关闭，需要自行勾选并设置。旧配置首次启动会自动补入三个关闭的条目，原有勾选和参数保留。

## 常用设置

### 启动公告

公告底部「我知道了」旁有 **下次更新前不再弹出** 复选框。勾选后再关闭，本版本内不再自动弹出；不勾选则只关闭这次。版本更新或公告内容变化时会重新提醒。

需要重看公告或恢复每次提醒时，可在 **设置 → 关于 → 查看欢迎信息** 中重新打开并调整勾选。

### 商店兑换

展开对应商店，打开需要的商品开关，再填写**目标份数**。名称中的 `*10`、`*100` 等表示一份包含的数量；商品与价格见 [商店商品清单](docs/商店商品清单.md)。

- **后勤商店按周累计**，周一北京时间 05:00 重置；精英、联合、大师商店按日累计，每日 05:00 重置。
- 同一周期重复运行，只补足尚未完成的目标。
- 填写数量超过库存或现有货币可兑换数量时，按游戏当前 **MAX** 兑换；售罄或余额不足时跳过。

### 装甲进阶

三种共鸣分别设置每周目标，**合计不超过 5 次**。目前仅支持已通关的 **1-5 地狱**，每次消耗 40 体力；游戏显示剩余 `0/5` 时跳过。建议排在活动清体力之前。

### 三个资源副本

在「作战」组分别展开 **异兽清剿、核心制造、队员特训**，启用需要的子类型，再填写关卡编号和每日目标次数（1～100）；例如关卡填写 `9` 表示 `1-9`。各任务都可以设置保留体力，默认按条目顺序使用已有体力；需要补充时另开下面的「自动补体力」。

异兽清剿包含经验获取、盾币获取、幻化星碎；核心制造包含生命、攻击、装甲、暴击、爆发、机动六种核心；队员特训包含防卫、攻击、火力、支援觉醒。各子类型可单独设置不同的关卡和次数。助手目标每日北京时间05:00重置，同一天、同一子类型和关卡重跑只补差额。

开放情况读取游戏当前的「常驻开放／星期开放／未开放」提示，兼容周年庆、双倍等临时全开活动。未开放、未三星通关或现有体力不足时记录原因并继续其他关卡；不会改打另一关，也不会启动手动作战。断网和识别失败会报错并保存截图，不会冒充未开放。扫荡结果未确认时保留记录，禁止重复提交。

建议把资源副本排在活动清体力之前。资料、实机核对范围见 [资源副本说明](docs/资源副本说明.md)。

### 自动补体力

展开资源副本、装甲进阶或活动清体力任务，开启 **自动补体力（不足时补充）**，填写每日最多使用几个体力道具；`0` 表示不用。默认关闭、所有额度默认 `0`，旧配置不会自动启用。先使用恢复50体力的道具，再使用恢复100体力的道具，每次只用1个。

需要结晶补充时，额外开启 **允许结晶购买体力**，同时设置每日最多购买次数与每日结晶总额；两项都大于0才会购买。每次按游戏当前价格重新核对，超过剩余额度或余额不足时跳过，不会充值。

**五个任务共用同一份每日用量，不是每个任务各领一份额度。** 各任务的设置表示它执行时允许的全日累计上限；建议填写一致，例如道具上限2，前面任务用完2个，后面就不能再用。每天北京时间05:00换日，同日重跑、重启助手都不会重新获得额度。

资源副本和装甲只为已选、可扫荡关卡补足尚需次数的体力，达到目标或额度就停；未开放、未三星、周次数用完时不补。活动清体力仅在不足一次时补到能扫荡，不循环补充清空。预览模式不使用道具或结晶。

提交前保存待确认记录，之后核对体力增加和道具库存减少；结晶购买核对游戏剩余购买次数减少1，余额显示精确数字时也核对扣除数。余额显示K/M等缩写时只用保守下界判断是否够用，不把缩写当精确余额。结果不明、断网或识别失败时保留记录并禁止自动重试。记录说明见 [自动补体力](docs/自动补体力.md)。

### 活动关卡

当前支持 **「艾吉斯·未解之谜」→「闪耀之始-7」**，每次消耗 **42 体力**，可在任务卡片中设置保留体力。2026-10-29 已重新核对入口，并实测扫荡1次、奖励结算及体力118→76；游戏显示探索截止 **2026-11-29 23:00（北京时间）**，兑换截止12月2日，清体力以探索截止为准。

提交前将本次次数、体力预算和截图写入 `runtime/state/event.json`；结算按钮兼容确认、确定和刷新，确认奖励及实际体力后才解除待确认状态。超时、断网或扣除不一致时保留记录，重启、换日或更换活动也不会自动清除。实测范围见 [活动实测记录](docs/活动实测记录.md)。

「续航计划」是限时活动，只领取已达成的累计体力消耗奖励，不消耗任何资源。建议排在活动清体力之后；活动下线、活动合集里找不到它时会自动跳过。

### 停止任务

点击 **停止任务**、按 **F8**，或双击 **停止助手.bat**。游戏中已经开始的竞技场代理会继续结算，之后可以再领取结果。

任务默认只使用现有体力和演习券；只有明确开启自动补体力并填写额度后才补充。不充值、不抽卡、不分解，也不取消运行中的远征。商店只兑换已勾选的商品；免费礼包会核对消耗为 0。

## 更新

在 **设置 → 更新** 中操作：

- **自动更新**：默认开启，助手运行期间定期检查新版，下载后等任务空闲再安装并重启。关闭后不会自动检查、下载或安装。
- **检查更新**：手动检查新版，发现新版后点击 **立即更新**。
- **同步资源**：重新下载与当前版本配套的识别资源，同步后重启助手，可用于修复资源缺失或损坏。

更新会保留任务勾选、数量、连接设置、主题外观和兑换记录。需要升级运行环境的版本会提示下载 Windows 完整版。

旧版本首次升级，或网络无法在线更新时，可关闭助手，完整解压新版，将 `CangwuMaa-v版本号` 文件夹**里面的内容**复制到旧版目录，覆盖同名文件，再从原来的启动入口启动。

更新时保留 **`app/config`、`config.local.json` 和 `runtime/state`**：它们保存任务设置、连接配置，以及兑换和共鸣进度。完整包不包含这些个人数据，不要删掉旧记录后重新开始。

## 常见问题

**找不到设备或连接失败？**

先确认 MuMu 已启动，在模拟器设置中启用 ADB 调试，然后刷新助手右侧的设备列表。助手默认使用专用连接端口 `15037`。仍有问题时，可运行 **仅检查连接.bat**；它会连接设备并检查识别，不点击游戏。

游戏需要重新登录、实名认证或下载资源时，请先按游戏提示手动完成，再重新开始任务。

**中途停止，后面的任务也没执行？**

先查看最早失败的任务日志。普通任务失败后，助手会先返回大厅再继续；停止指令、失去设备连接、启动失败或用完运行预算时会停止后续操作。单轮上限默认45分钟或500次操作，未完成的目标可以分轮补足。待确认的兑换／扫荡仍需先核对记录。

**提示存在待确认的兑换／扫荡／补体力记录？**

先核对游戏中是否已经扣款、扣次数或发放奖励，再查看 `runtime/runs` 中对应的截图。**不要直接删除记录重跑**，以免重复兑换或消耗。无法确认时请提交问题反馈。

**支持其他模拟器、服务器或关卡吗？**

目前适配 Windows x64、MuMu 和苍雾世界国服；其他环境尚未适配。远征会沿用已保存的队伍和任务，首次使用请先在游戏中保存队伍，并使时长与助手设置一致。
