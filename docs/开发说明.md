# 开发说明

普通使用者请下载 [Windows 完整包](https://github.com/robot234/cangwu-maa/releases/latest/download/CangwuMaa-Windows-x64.zip)，从根目录启动。本页面向源码开发与打包。

## 源码安装

使用 Windows x64 和 64 位 Python 3.13。在项目目录执行：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-windows.lock
.\.venv\Scripts\python.exe tools\setup_runtime.py
```

安装脚本按 `DEPENDENCIES.json` 下载并校验固定版本的 MXU 与 Maa 设备辅助程序，原生库来自 Maa Python 包。安装过程不连接游戏。

界面定义在 `app/interface.json`，资源在 `app/resource`，Agent 入口在 `agent/main.py`，游戏流程在 `cangwu`。修改任务选项后可运行 `tools/build_feature_options.py` 重新生成商店、共鸣、资源副本及补体力选项。

## 检查

```powershell
.\.venv\Scripts\python.exe tools\validate_resources.py
.\.venv\Scripts\python.exe tools\setup_runtime.py --check
```

这些检查只验证任务资源和运行库，不操作游戏。

连接检查使用 `tools/run_maa.py --tasks check`，会连接真实设备并截图，不点击游戏。专用 ADB 服务端口为 15037，禁止重置或操作 5037。

## 构建 Windows 完整包

```powershell
.\.venv\Scripts\python.exe tools\build_portable.py
```

构建工具使用官方 Python 嵌入式发行版、锁定的 Python wheel 和官方 Maa／MXU 运行库，在 `runtime/dist` 内新建独立发行目录并输出 `CangwuMaa-Windows-x64.zip`、`SHA256SUMS.txt`。只复制明确列出的源码与资源，不复制本机虚拟环境、个人设置、日志或状态。

运行环境均在包内，支持解压和移动目录；不依赖构建机的基础 Python。发布前应使用包内 Python 验证资源和原生加载，并在含中文及空格的新路径下运行检查。构建脚本不会创建标签或上传 Release。

## 构建在线更新包

从同一版已验证的完整包目录生成更新资产：

```powershell
.\.venv\Scripts\python.exe tools\build_update.py --package-dir runtime\dist\CangwuMaa-v版本号 --output-dir runtime\dist
```

将 `CangwuMaa-Update.zip` 的 SHA256 一并写入 Release 的 `SHA256SUMS.txt`，与完整版和 MXU 对应源码包同时发布。在线更新包包含脚本、界面和识别资源；运行环境变更需升级完整版。资源同步使用已安装版本对应的 Release，自动更新只使用正式最新版。

## 本地数据

| 路径 | 内容 |
| --- | --- |
| `app/config` | MXU 任务及设备设置 |
| `config.local.json` | 本地连接与任务配置，可选 |
| `runtime/state` | 商店／共鸣／资源副本进度、共用补体力额度及待确认记录 |
| `runtime/runs` | 游戏任务日志、截图与结果 |

更新时保留这些目录。待确认记录不得自动清除或重试提交。
