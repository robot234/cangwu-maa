# 验证说明

当前版本：0.4.0；实机核对日期：2026-10-17。使用Windows x64、MuMu、国服及1280×720基准画面。其他账号的解锁进度、远征队伍和活动状态可能不同。

## 可重复的本地检查

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tools\validate_resources.py
.\.venv\Scripts\python.exe tools\setup_runtime.py --check
```

单元检查使用构造的页面数据，覆盖消耗核对、停止保护、远征续派、结算恢复、积分奖励、商店数量上限、周目标去重及未知交易结果阻断等逻辑。interface与pipeline使用随仓库提供的官方Schema校验。

## 已有实机证据的范围

- MXU启动后搜索与连接设备，专用ADB服务端口15037。
- 指挥室收取、两队远征领取与12小时续派、活动关卡扫荡、竞技场代理结算、每日积分及通行证奖励领取。
- 首页推荐免费礼包的0消耗领取与再次运行跳过。
- 精英17项、后勤12项、联合9项、大师14项的实际页面识别，以及商品图、价格与币种核对。
- 商店配置999份时，实机MAX分别限制为40、50、5份；均在核对后取消，没有真实扣币。后勤售罄商品跳过，未选择项目时零游戏输入。
- 当前账号本周共鸣剩余0/5时跳过。

商店真实兑换后的奖励与库存闭环、资产不足的正向实机场景、后勤下一周刷新、有剩余次数时的共鸣正向扫荡，尚无当前版本的完整实机闭环证据；相关逻辑有单元检查，不等同于实机通过。

原始账号截图、日志、设备配置与本机验收记录不公开。开发工具`verify_replays.py`、`verify_feature_replays.py`需要自行准备兼容的`tests/fixtures`，该目录不包含在仓库中。`mxu_feature_acceptance.py`只作预览后取消；正式任务会按界面中保存的选择实际执行。
