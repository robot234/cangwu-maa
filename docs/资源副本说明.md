# 资源副本

新增三个独立条目，默认关闭；每种子类型可分别配置关卡、每日目标次数（1～100），每个条目可设置保留体力。默认不补体力，可另开「自动补体力」并设置额度，详见[自动补体力](自动补体力.md)。不会启动手动作战。

| 独立条目 | 子类型 | 关卡编号 |
| --- | --- | --- |
| 异兽清剿 | 经验获取、盾币获取、幻化星碎 | 1～10 |
| 核心制造 | 生命、攻击、装甲、暴击、爆发、机动 | 1～5 |
| 队员特训 | 防卫、攻击、火力、支援 | 1～10 |

## 开放规则与资料

- [官方双倍与体力续航公告](https://www.taptap.cn/moment/805377113841469939)明确说明，活动期间核心制造和队员特训全天开放。该公告的活动时间为2026年5月28日至6月3日，不能用来推断当前活动结束时间。
- [官方2025年6月19日维护公告](https://www.taptap.cn/moment/684416129875050792)也包含资源副本活动期间全天开放的规则。
- [玩家原始攻略及副本截图](https://www.taptap.cn/moment/711885409914718641)展示异兽清剿的常驻开放，以及核心、特训各子类型的星期开放标签。属于历史截图，不把它当成当前周年庆的开放日历。
- 2026年10月27日本机核心制造的帮助图鉴说明，能够获得的核心碎片种类每天不同；本次活动界面的子类型标签显示「常驻开放」。

因此程序不内置一张可能过期的星期表，而是识别所选子类型当前显示的开放标签。显示「常驻开放／全天开放／今日开放」时按开放处理；明确未开放或当前星期不在游戏显示的星期范围时跳过。换日附近不凭日期推断，继续核对游戏的实际切换结果。未读清、页面不响应和网络异常属于失败，不标记为未开放。

## 体力与重复运行

单次体力读取所选关卡详情，再与扫荡预览中的次数、总消耗、当前体力逐项核对。超过已有体力或保留体力时只执行可负担次数；不足一次时跳过。未满足三星条件时跳过，不尝试打通关。

助手每日目标按北京时间05:00分段，各子类型及关卡分别累计。扫荡提交前先写入 `runtime/state/resource_*.json` 的待确认记录；只有收到结算并核对体力变化后才累计次数。结果不确定时保留记录，跨日也不会自动清除或重试。

## 验证

实机检查仅打开详情和扫荡设置后取消，没有提交资源扫荡。详细截图、预览核对和最终验收结果保存在本机 `runtime/runs` 与 `runtime/resource-acceptance.json`；未开放路径使用测试画面验证，活动全开期间无法声称已实测自然关闭状态。
