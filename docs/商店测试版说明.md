# v0.4.11 商店修复验证范围与升级说明

修复 Issue #1 所述的余额不足误提交，并在再次运行商店任务时自动重新识别、核对上次结果。人工核对入口仅保留作无法判断时的后备。

## 已完成的验证

- 343 项自动测试通过，包括余额不足、MAX 无响应、重新进入商店两次自动核对、旧预览重识别、跨天库存刷新保护、原周期记账、人工兜底和停止指令保护。
- 实际 Maa OCR／模板的 10 组离线回放通过，覆盖 5 种商店货币、库存重置倒计时、自动判断已成交，以及旧记录重新读取截图后自动判断未成交。自动核对回放模拟界面导航，禁止设备输入。
- 其中一组为人工构造的「余额 2295、单价 7500、数量 1」回归图，确认返回跳过，未点击 MAX 或确认。

- 实际游戏中完成大师商店幻化星碎 1 份兑换，扣币 5、库存减少 1，奖励及账本一致；以相同总目标重跑时操作数为 0，没有重复兑换。
- 用真实兑换前证据建立独立的模拟待核对记录，两次重新进入游戏商店读取余额和库存，已成交、未成交两条核对分支均通过。模拟记录与真实消费账本分开保存。

**已完成模拟测试及上述部分实机验证，仍需要反馈者按原问题的低余额场景实际测试。** 余额 2295、单价 7500 的原场景使用人工构造截图离线回放，没有在实际低余额账号原样复现；异常恢复使用模拟待核对记录，没有制造自然故障。单商品实测不代表所有商店和商品都已实测。

安装或打开助手本身不会更改旧记录；再次开始商店任务时先自动核对，证据一致后才结案。旧截图缺失、数据有冲突、无限库存或无法排除库存刷新时仍保留待核对。

## 怎样升级与实际测试

1. 停止并关闭旧助手，保留旧目录作回退。
2. 下载 v0.4.11 完整包，完整解压到新目录。
3. 如果沿用原有设置和进度，将旧目录中的 `app/config`、`config.local.json`（如有）、`runtime/state` 和 `runtime/runs` 复制到新目录相同位置。保留原始目录；不要丢弃旧的待核对账本后重新执行商店任务。
4. 在新目录双击 `启动苍雾助手.bat`。币种、余额未读清会停止兑换；买不起的商品会取消预览并跳过。
5. 若已有商店待核对提示，正常再次运行该商店任务。已成交会给原周期补记数量，避免重复补兑；未成交会解除待核对，再按当前余额和目标继续。旧版没有准确提交时间时，首次核对会额外等待约 30 秒。
6. 只有自动核对仍无法判定时，才先停止任务，再使用 `核对商店兑换.bat` 人工处理；不能确认则选 `0` 保留锁定。

请重点确认：余额不足时会跳过且不新增待核对；保留旧记录再次运行后能否自动核实结果。仍失败时请保留对应日志和前后截图，反馈到 Issue #1。

完整核对流程和新证据字段见 [商店兑换核对](商店兑换核对.md)。发布包不包含个人设置、运行记录或账号截图；复制自己的历史数据后，这些内容仍只保存在本地。
