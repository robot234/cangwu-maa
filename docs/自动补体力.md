# 自动补体力

在异兽清剿、核心制造、队员特训、装甲进阶或活动清体力中展开选项，打开「自动补体力」。默认关闭，各项额度默认0。每个任务可以控制是否允许补充；开启后先用50体力道具，再用100体力道具，每次只用1个。

「每日最多使用几个」是两种道具的合计个数，上限100。若需要使用结晶，须独立开启「允许结晶购买体力」，再设置购买次数（0～30）和结晶总额（0～99999），两者均须大于0。道具没有了或已达到道具额度，才考虑结晶；结晶当前价格超过剩余额度、余额不足或游戏剩余次数为0时跳过。

五个任务共用 `runtime/state/stamina_refill.json` 中的每日累计，不按任务分别发放额度。各任务填写的是它执行时可接受的全日累计上限，建议设为相同值。同一天重复运行、切换任务或重启不会重置用量，北京时间05:00换日；待确认记录不随换日清除，系统时间倒退时也不会重置额度。

资源副本和装甲按当前关卡的目标差额计算所需体力，达到目标或额度后停止补充。关卡未开放、未三星或装甲周次数用完时不补。活动清体力只补足一次扫荡所需，不循环补充清空；活动过期时不会为了补体力继续执行。已有体力够用时不打开补充窗口。

提交前核对选中边框、道具／结晶图标、使用数量1、回复量和结晶价格，并先保存待确认记录。提交后核对体力增加及道具库存减少1；结晶购买核对游戏剩余购买次数减少1。余额为精确数字时另核对扣除金额，K/M等缩写只用于保守判断是否够用。核对失败时不清除待确认记录，不自动重试。不要直接删除记录重跑。

截图、OCR、模板、点击及返回均使用 MaaFramework。补充窗口仅在该流程内临时许可；预览许可拒绝「确认」，充值、其他购买和未知窗口仍然拦截。
