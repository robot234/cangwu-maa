# v0.4.14 验证与升级说明

新增两个限时活动，并修正武道会跳过确认和活动扫荡误停。

## 新增与修正

- **宇宙武道会**：读取剩余免费次数，用完后领取每日、当期达标任务奖励。每回战点击右侧跳过，并确认“是否跳过此次战斗，直接显示结果？”弹窗，再核对结算及免费次数减1。保留未确认匹配，恢复时先核对原场次，不购买次数、不修改队伍。
- **酒吧闲谈**：固定选中间罐子，核对资源奖励及“今日已参与活动”，同日重跑跳过；领取结果不明时保留待确认记录。
- **活动扫荡预览**：黄色零识别较弱时，只放大重读体力变化区域，保持原置信度和体力核对要求。
- **活动扫荡升级弹窗**：保存并核对升级恢复的体力，再关闭弹窗、核对地图上的实际体力；返回大厅时也会先收起已识别的升级弹窗。

## 升级

完整包解压后从根目录启动；已有安装可使用程序更新。旧配置启动时自动补入两个默认勾选的新活动，原任务勾选、参数和ID保留。两个活动入口消失时跳过。

保留 `app/config`、`config.local.json` 和 `runtime`，其中保存个人设置、进度、待确认记录及历史截图。当前活动“闪耀之始-7”探索截止2026年11月29日23:00（北京时间），到期后需要重新适配。
